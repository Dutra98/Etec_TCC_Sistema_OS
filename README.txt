Sistema de Gestão de Ordens de Serviço

Este projeto é um protótipo web desenvolvido para o Trabalho de Conclusão de Curso Técnico em Desenvolvimento de Sistemas.

Objetivo:
Simular um sistema de cadastro e listagem de Ordens de Serviço para uma assistência técnica.

Estrutura do projeto:
- frontend/index.html: tela de listagem das Ordens de Serviço.
- frontend/pages/nova-os.html: tela de cadastro de nova Ordem de Serviço.
- frontend/css/style.css: arquivo de estilos do sistema.
- frontend/js/script.js: funções básicas em JavaScript.
- backend/app.py: estrutura inicial planejada para o backend em Flask.
- backend/database/database.sql: estrutura planejada do banco de dados relacional.

Como executar o protótipo:
1. Abra a pasta frontend.
2. Abra o arquivo index.html no navegador.
3. Clique no botão Nova OS para acessar a tela de cadastro.
4. Preencha os dados e clique em Salvar.
5. Os dados são armazenados temporariamente no navegador usando localStorage.

Observação:
Nesta etapa, o sistema funciona como protótipo frontend. A pasta backend contém a estrutura inicial planejada para futura integração com Flask e banco de dados.
